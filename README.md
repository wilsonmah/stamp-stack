# 叠印 Stamp Stack

新中式水墨风的叠层三消小游戏。层层叠叠的牌中，只能拾取没被压住的那一枚；同字三枚自成一印、随即消散；槽满七枚即告失败。

- 关卡以二十四节气命名，第一关热身，第二关见真章
- 每关都由程序生成，并保证至少存在一种通关解法
- 节气天象（第三关起）：每个节气一种天象，五种机制轮换
  - 春雷：倒数归零时一声雷，顶层两枚牌的字互换
  - 冰封：部分牌被冰封，敲一下破冰、再点才能拿，还会不断有新牌被冻住
  - 薄雾：上半区笼着雾，字迹看不清，消得越多雾越散
  - 墨雨：雨水洇湿可拿的牌，字迹短暂模糊
  - 落叶 / 落花 / 积雪：盖住一枚牌，点一下才能扫开，偏爱落在你正缺的字上
- 道具：移出 / 撤回 / 洗牌，每关各一次；失败时可用「移出」续命
- 纯 HTML，单文件，无依赖，iPhone Safari 直接玩，可「添加到主屏幕」

在线游玩：https://wilsonmah.github.io/stamp-stack/
